# GiTool

GiTool 是一款面向 Windows 的 Git 辅助工具：把分散在多个目录里的仓库集中登记起来，自动扫描本地与远程的差异，并在同一个界面中完成分支选择与推送。

界面使用 PySide6 完全自绘，支持 macOS 与 Win11 两种窗口风格、深浅色主题，以及可选的系统身份校验。

## 核心特性

- **首页汇总**：一眼看到仓库总数、待推送数量、本地与远程不一致的仓库数、未配置远程的仓库数
- **仓库来源管理**：可以添加单个 Git 仓库目录，也可以添加一个上级文件夹并自动递归扫描其中的仓库；多个来源统一登记，目录来源可展开/收起查看其下的仓库，支持随时移除
- **仓库详情**：点击任意仓库条目进入详情页，集中管理远程仓库（添加、改地址、删除）、勾选多个远程作为批量推送目标，并直接推送、抓取或拉取；推送与拉取状态、领先/落后数量与工作区改动一目了然
- **推送面板**：可推送的条目自动置顶，组内按名称排序；点击条目右侧箭头在原位置展开详情卡，选择远程分支后推送
- **分支切换**：存在多个本地分支的仓库，可在条目内直接切换分支，详情与推送均以所选分支为准，切换时内容带过渡动画
- **一次扫描全局复用**：首页、仓库、推送共用同一份扫描结果，来源未变化时不会重复执行 git
- **敏感操作二次校验（Beta）**：实验功能，默认关闭；开启后，推送前会调用 Windows Hello（PIN / 指纹 / 人脸）验证身份，关闭该保护本身同样需要验证
- **界面风格**：内置 macOS 风格（自绘交通灯）与 Win11 原生标题栏两种风格，深浅色可跟随系统或手动指定，偏好本地持久化

## 安装与运行

### 从源码运行

要求 Windows 10/11、Python 3.10 及以上（开发环境为 3.12）、Git。

```bash
pip install -r requirements.txt
python GiTool.py
```

`requirements.txt` 中的 `winrt-runtime` 与 `winrt-Windows.Security.Credentials.UI` 仅用于 Windows Hello 身份校验。

### 安装包

发布版通过 Nuitka 打包、Inno Setup 生成安装程序 `GiTool_Setup.exe`，安装后从开始菜单启动即可。

## 使用方法

1. 打开「仓库」页，点击「添加仓库」选择单个 Git 仓库目录，或点击「添加文件夹」选择上级目录批量扫描
2. 目录来源会以二级条目的形式列出所有扫描到的仓库，点击目录条目可展开或收起
3. 点击任意仓库条目进入仓库详情：配置远程、勾选批量推送目标，或直接推送 / 抓取 / 拉取，按 Esc 或「返回」退出
4. 切到「首页」查看汇总统计
5. 切到「推送」页，点击条目右侧箭头展开详情，确认远程与分支后点击推送
6. 推送完成后列表会保持当前滚动位置，首页统计同步刷新

## 设置

- **常规**：显示应用名称与版本
- **个性化**
  - 界面风格：macOS 风格 / Win11 系统风格
  - 深浅色模式：跟随系统 / 浅色 / 深色
- **安全**
  - 敏感操作二次校验（Beta）：实验功能，默认关闭。开启后推送需要先通过系统验证；关闭该开关本身也需要验证，验证失败时开关保持开启

## 数据与隐私

- 配置保存在用户目录下的 `~/.gitool/config.json`，内容包括仓库来源列表、界面风格、深浅色、安全开关与各仓库的批量推送目标
- 所有信息仅保存在本机，程序不收集、不上传任何用户数据，也不会主动发起网络请求
- 所有仓库扫描与推送操作均通过本机 Git 命令完成

## 技术栈

- Python 3
- PySide6（Qt 6，完全自绘界面）
- 本机 Git 命令行
- Windows Hello（winrt）
